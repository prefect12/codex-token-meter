# AI Token Meter 0.2.24

Released: 2026-09-10

- Add a first-class Hours page above Calendar with one stacked bar per hour and per-model color breakdowns.
- Switch between rolling 24-hour and 48-hour ranges, with an option to hide hours that contain no usage.
- Select one hour, Command-select multiple hours, or drag across bars to inspect the combined model details; clicking empty space restores the full-range summary.
- Browse historical dates with previous/next-day controls and a compact native calendar popover; historical scans are debounced and cached to keep date changes responsive.
- Improve hourly model attribution across Codex, Claude Code, and OpenCode data so nested sessions are less likely to appear as an unknown model.
- Refine the Hours toolbar, legend spacing, model summary, and accessible labels for the new controls.

This release updates AI Token Meter only; Task Bar is unchanged.
