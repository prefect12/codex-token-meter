# AI Token Meter 0.2.22

Released: 2026-09-05

- Add GPT-6 Astra standard API-equivalent pricing: $10 input, $1 cached input, $12.50 cache writes, and $50 output per million tokens. Manual prices and the online pricing catalog retain their existing precedence.
- Include Astra in the offline Codex model list. When available, the local Codex catalog remains authoritative for models and reasoning levels, including Codex's Ultra mode.
- Include Astra in the initial reasoning comparison alongside the GPT-5.6 subscription family; existing saved selections remain unchanged.
- Preserve token accounting, provider partitions, and unknown-model price coverage.

These are standard-rate API-equivalent estimates, not additional subscription charges. Aggregate logs do not identify all per-request long-context, Fast, Batch, or Flex adjustments, so those adjustments are not reconstructed. Official rates: https://developers.openai.com/api/docs/models/gpt-6-astra

This release updates AI Token Meter only; Task Bar is unchanged.
