# AI Token Meter v0.2.28

修复 Codex 历史日志压缩迁移后，本地 Token 总量、日历和模型统计明显下降的问题。

- 支持读取 `.jsonl.zst` 历史日志及多段 Zstandard 压缩帧，保留累计计数差值与模型归属。
- 同一路径同时存在普通与压缩日志时只统计一次，避免迁移期间重复计数。
- 流式读取压缩日志，不在磁盘展开原始历史；按块和文件释放临时对象，降低首次扫描内存占用。
- 解压失败不会被保存为零用量缓存，后续可重试。

压缩历史读取依赖本机已安装的 `zstd`，支持 `/opt/homebrew/bin/zstd`、`/usr/local/bin/zstd` 和 `/usr/bin/zstd`。未修改原始日志，未用官方账户总量补造本地模型明细。

验证覆盖多帧、跨读取块的大记录、末尾无换行、累计差值、双格式去重、日/小时及项目统计、缓存重读与损坏文件重试。
