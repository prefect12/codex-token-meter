# AI Token Meter v0.2.29

新增 Aiberm 实际账单与菜单栏账户余额。

- 「API 账单」页分别展示账户钱包余额、账户累计扣费与请求数、当前 API key 累计扣费及配额。
- 自动识别 Claude Code 或 Claude App 当前已应用的 Aiberm 配置；账户余额需单独连接控制台账户，验证成功后将系统访问令牌保存在本机 macOS 钥匙串。
- 菜单栏可选择「Aiberm 余额」替换 Claude 百分比，并保留 Codex 指标。每 60 秒刷新；未授权显示 `A$—`，刷新失败或超过 3 分钟时用 `~` 标记缓存余额。
- 无限 key 配额不会被误当作钱包余额；平台累计扣费包含所有设备共用 key 的消费，与本地 API 费用估算独立。
- 账单只发起 GET 请求，限制 Aiberm HTTPS 主机，拒绝重定向；缓存不包含密钥或访问令牌。

系统访问令牌具备账户 API 权限，并非只读专用。本应用仅用它读取余额与请求数；可在「API 账单」页断开账户并删除本机授权。

验证：计费单位换算、key/账户边界、异常响应、凭据轮换与缓存权限测试通过，既有 API 用量回归通过；已核对原生账单页面和菜单栏余额格式。
