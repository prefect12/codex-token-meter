# v0.2.17

> Released: 2026-07-28

## Highlights

- **更直观的周额度节奏** — AI Token Meter 概览页现在同时显示 Codex 与 Claude 的周剩余额度、重置时间和按时间推算的预期剩余标记。
- **Task Bar 计划进度** — Codex 任务行新增紧凑的计划进度环；悬浮可查看完整计划，运行中与已完成状态会正确动画和收口。

## Improvements

- AI Token Meter 详情页滚动改为图层合成，并减少年度日历、倒计时和后台聚合的重复工作。
- 思考分析页在有数据时默认比较 GPT-5.6 Sol 与 Terra，同时保留手动模型选择。
- Task Bar 的任务详情与计划悬浮面板跟随鼠标，并在多显示器边缘保持可见。
- 已确认的历史子任务不再重新出现在 Task Bar 中。

## Fixes

- 修复 `claude-opus-5` 未匹配 API 价格、日历模型行显示 `—` 的问题。
- 修复子智能体 Token 被错误归入 `codex` 模型的问题；受影响的本地聚合缓存会自动重建。
- AI Token Meter 不再自动弹出 Claude Keychain 密码授权；缺少授权或钥匙串锁定时会静默回退到 statusline 或缓存数据。
- 修复 Task Bar 长时间运行后 SQLite 读取进程和工作线程累积导致的高 CPU、刷新延迟或菜单无响应。
- 修复已完成任务的计划仍停留在未完成步骤，以及运行中进度缺少动态反馈的问题。
