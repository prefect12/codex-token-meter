# v0.2.21

> Released: 2026-08-31

## Highlights

- **项目配置分区独立继承** — 运行策略、上下文压缩和 Plan 模式可分别选择跟随全局或使用项目覆盖，不再被一个总开关绑定。
- **新项目自动生成配置** — Codex 新项目首次被发现且缺少 `.codex/config.toml` 时，会一次性复制当前全局默认值创建项目配置；已有文件不会被覆盖。
- **上下文配置更直观** — 有效上下文窗口与自动压缩阈值支持滑动和数字输入，并以固定 `K` / `%` 单位显示。

## Fixes

- 修复在 AI Token Meter 中保存全局配置时，被保护 watcher 误判为 Codex 会话临时选择并改写当前项目配置的问题。
- 保存全局配置现在只修改全局配置文件；已经创建的项目配置保持独立不变。
- 保留 Codex 外部模型选择的短暂任务覆盖能力，不影响原有默认值保护与自动恢复。
