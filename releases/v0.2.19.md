# v0.2.19

> Released: 2026-08-04

## Highlights

- **模型页支持自定义日期范围** — 可快速切换 7/30/90 天，也可分别选择起止日期；切换预设时优先复用缓存和内存数据，避免反复扫描日志造成界面卡顿。
- **Claude 默认模型配置** — “默认模型”页面现在可在 Codex 与 Claude 之间切换，并设置全局及项目级模型与思考强度；Claude 项目覆盖写入私有的 `settings.local.json`，不会修改共享项目配置。
- **更完整的模型活动指标** — 日历和模型明细统一显示会话、轮次、用量记录、Token、周额度占比和 API 等价成本，相关术语也已统一说明。

## Improvements

- Codex 与 Claude 的模型配置在外部文件变化后会自动同步，无需重新打开页面或手动刷新。
- 默认模型入口移到“设置”上方，平台切换按钮与现有来源筛选保持一致。
- 日历模型表会根据窗口宽度自适应列数，并在宽屏下逐步展示更多指标。
- “Token 事件”改名为“用量记录”，避免被误解为 Token 数、对话轮次或请求数。

## Fixes

- 修复旧缓存缺少新增活动指标时被错误解读为零的问题，升级后会自动重建相关聚合缓存。
- 修复周视图模型额度占比显示为破折号、概览模型元数据截断和窄窗口日历表格重叠。
- Task Bar `0.1.20` 修复新版 Codex Desktop 记录格式导致的计划解析失败，并恢复有计划任务悬浮时的固定按钮。
